# CoY Engine

Gameplay tuning for NBA 2K27 on PC, offline.

## Install
1. Download `CoY_Engine.exe` from the latest release.
2. Close the game, run the exe and click **Install / update CoY Engine**.
3. Follow the setup guide shown in the window.

**Restore 2K original** puts the original file back.

## Setup guide
1. **Start NBA 2K27 offline**, then connect to 2K Share and download these files by **sheitanlevrai**:

   | File | Name |
   |---|---|
   | Roster | CoY Roster 1.0 |
   | MyNBA | CoY MyNBA OpenNight |
   | MyNBA + G League | CoY MyNBA OpenNight With Gleague |
   | Sliders | CoY HoF |

2. **Use these settings** in the game options and MyNBA coach settings:

   | Setting | Value |
   |---|---|
   | Game speed | 40 |
   | ACE | Off (offense and defense) |
   | Substitutions | Rotation |
   | Freelance | Dynamic, Do not repeat |

## How updates work
The exe reads `latest.json` in this repo and installs the file built for your exact game version.
After an update, run the exe again once the matching CoY Engine file is published here.
