# CoY Engine

Gameplay tuning for PC, offline.

## Install
1. Download `CoY_Engine.exe` from the latest release.
2. Close the game, run the exe, choose **[1] Install / update**.
3. Load the CoY HoF sliders.

**[2] Restore** puts the original file back.

## How updates work
The exe reads `latest.json` in this repo and installs the file built for your exact game version.
After an update, run the exe again once the matching CoY Engine file is published here.
