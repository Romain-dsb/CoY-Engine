# CoY Engine

Gameplay tuning for NBA 2K27 (PC, offline).

## Install
1. Download `CoY_Engine.exe` from the latest release.
2. Close the game, run the exe, choose **[1] Install / update**.
3. Keep the game sliders at 50.

**[2] Restore** puts the original 2K file back.

## How updates work
The exe reads `latest.json` in this repo and installs the file built for your exact game version.
After a 2K update, run the exe again once the matching CoY Engine file is published here.
